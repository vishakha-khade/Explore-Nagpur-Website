# Explore Nagpur Website

A modern and elegant static website that showcases the beauty, culture, and tourist attractions of Nagpur, Maharashtra.

## Overview

Explore Nagpur is a responsive travel and city-guide website designed to help visitors discover the city’s historical places, scenic spots, local culture, and contact information. The project is built using plain HTML and CSS, making it lightweight, easy to run, and beginner-friendly.

## Features

- Beautiful home page with hero section
- Tourist attraction highlights
- About page describing the city
- Places page showcasing popular destinations
- Contact page for inquiries
- Responsive and clean design
- No backend required

## Tech Stack

- HTML5
- CSS3
